# V3RAnalytics — pacotes

Este repositório só distribui os pacotes do plugin **V3RAnalytics** para WordPress. O código-fonte é privado.

## Baixar a versão mais recente

Link fixo, sempre aponta para a última versão publicada:

https://github.com/V3RTECH-DF/V3RAnalytics-Releases/releases/latest/download/v3ranalytics.zip

No WordPress: **Plugins > Adicionar novo > Enviar plugin**, escolha o arquivo e ative. Depois da instalação, as atualizações chegam sozinhas pelo painel do WordPress.

## Versões

Cada versão é uma *release* desta página, com o arquivo `v3ranalytics.zip`.
